# 한눈AI 사용가이드

한눈AI는 복잡한 내용을 **60자 이내 한 문장**과 **다이어그램 이미지**로 정리합니다. 회원가입·로그인·AI API 키 입력 없이 서비스 주소에서 바로 사용할 수 있습니다.

웹 상단 **사용가이드**에서 화면에 맞는 안내와 실제 MCP 주소를 확인할 수 있습니다.

## 웹에서 사용하기

1. 한눈AI 서비스 주소를 여세요.
2. 텍스트 또는 공개 웹페이지 URL을 붙여넣거나 파일을 선택하세요.
3. **다이어그램 만들기**를 누르세요.
4. 결과를 확인하고 **이미지 복사** 또는 **PNG 다운로드**를 사용하세요.

**다시 생성하기**는 같은 원문으로 새 결과를 만듭니다. 새 생성도 이용 한도에 포함됩니다. **지우기**는 입력 화면을 비웁니다.

## 자료 준비하기

| 입력 | 사용 방법 |
|---|---|
| 텍스트 | 한 번에 최대 12,000자까지 붙여넣습니다. |
| URL | 공개 웹페이지 주소를 넣습니다. 로그인 페이지·가져오기가 막힌 사이트는 Chrome 확장 또는 텍스트 입력을 이용합니다. |
| 파일 | 최대 10MB. txt, docx, html, hwpx, pdf(텍스트로 인식되지 않는 이미지형 PDF 파일은 제외) |

파일을 선택하면 이름·용량과 준비 상태가 표시됩니다. 파일의 본문은 브라우저 안에서 읽고, 만들기 버튼을 눌렀을 때 추출한 본문을 분석 서버로 보냅니다. 원본 파일 전체를 서버로 업로드하지 않습니다.

PDF의 문장을 마우스로 선택해 복사할 수 있는지 확인하세요. 스캔한 종이처럼 글자가 이미지인 PDF, 암호가 걸린 파일, 손상된 파일은 읽지 못할 수 있습니다. PDF는 최대 80페이지까지 확인합니다. 일부 페이지만 읽혔거나 글자 수를 넘었다는 안내가 보이면 필요한 구간을 직접 입력하거나 문서를 나누세요. 표·그림·수식의 배치는 텍스트로 완전히 전달되지 않을 수 있습니다.

## 결과 활용과 보관

- **이미지 복사:** 문서·메신저에 붙여넣습니다. 복사가 안 되면 다운로드를 사용하세요.
- **PNG 다운로드:** 결과를 이미지 파일로 저장합니다.
- **다시 생성하기:** 같은 원문을 다시 정리합니다.
- **지우기:** 입력과 결과 표시를 비웁니다.

AI의 해석에는 차이가 있을 수 있으므로 중요한 조건·숫자·관계는 원문과 확인하세요. 하단 확인 안내가 보이면 해당 내용을 특히 살펴보세요.

결과의 기본 보관 기간은 24시간입니다. 브라우저를 종료하거나 사이트 데이터를 지우면 최근 결과를 다시 열지 못할 수 있으므로 필요한 이미지는 바로 저장하세요. 접속 환경과 서비스 전체의 이용 한도에 도달하면 잠시 후 또는 다음 날 다시 이용해야 합니다.

## Chrome 확장 프로그램 설치

웹만 이용한다면 설치하지 않아도 됩니다. Chrome 설치와 권한 승인은 사용자가 직접 해야 합니다.

1. 한눈AI 웹 **사용가이드 → Chrome 확장 프로그램 다운로드**를 누르세요.
2. ZIP의 압축을 푸세요. Windows는 ZIP을 마우스 오른쪽 버튼으로 눌러 **압축 풀기**, Mac은 ZIP을 두 번 클릭합니다.
3. Chrome 주소창에 `chrome://extensions`를 입력하고 Enter를 누르세요.
4. 오른쪽 위 **개발자 모드**를 켜세요.
5. **압축해제된 확장 프로그램을 로드합니다**를 누르세요.
6. ZIP 자체가 아니라 `manifest.json` 파일이 들어 있는 폴더를 선택하세요.
7. Chrome 오른쪽 위 퍼즐 모양 아이콘에서 한눈AI 옆 핀을 눌러 고정하세요.
8. 정리할 웹페이지를 열고 한눈AI 아이콘 → **현재 페이지 정리하기**를 누르세요.
9. 처음에 서비스 연결 권한을 요청하면 한눈AI 서비스 주소를 확인하고 허용하세요.

다운로드에는 해당 서비스 주소가 이미 설정되어 있습니다. 코드 수정·키 입력·로그인은 필요 없습니다. 압축을 푼 폴더는 설치 후에도 유지하세요.

**크게 보기**는 한눈AI 웹페이지를 엽니다. 텍스트·URL 입력, 파일 선택, 이미지 복사·다운로드도 사용할 수 있습니다. 팝업을 닫았다가 다시 열면 최근 작업을 불러오지만 브라우저를 완전히 종료하면 다시 접근하지 못할 수 있습니다.

현재 탭 권한은 정리 버튼을 눌렀을 때 현재 페이지의 보이는 본문을 읽는 데 사용합니다. 방문 기록을 수집하거나 다른 탭을 계속 읽지 않습니다. Chrome 내부 화면·웹 스토어·일부 PDF 뷰어·영상 중심 페이지는 읽을 수 없습니다. 필요한 내용을 텍스트로 입력하거나 파일을 선택하세요.

업데이트는 새 ZIP을 받은 뒤 기존 확장을 제거하고 새 폴더를 로드합니다. 제거는 `chrome://extensions`의 한눈AI 카드에서 **삭제**를 누릅니다. Chrome 웹 스토어 링크가 별도로 제공되면 스토어 설치 버튼과 권한 승인으로 설치할 수 있습니다.

## MCP로 AI 채팅에 연결하기

MCP는 AI 채팅에 한눈AI 도구를 추가하는 기능입니다. 한눈AI 계정이나 AI API 키는 필요 없습니다. 이용 중인 AI 채팅 서비스의 계정·요금제·권한은 별도입니다.

MCP 주소는 **서비스 주소 + `/mcp`**입니다. 웹 가이드의 **주소 복사**를 사용하세요. `localhost`·`127.0.0.1`은 그 PC에서만 접근되므로 ChatGPT나 다른 PC에는 공개 HTTPS 주소가 필요합니다.

### ChatGPT 웹

1. **설정 → 앱**에서 만들기 또는 사용자 지정 앱 추가 항목을 찾습니다.
2. 계정에서 요구하면 고급 설정의 개발자 모드를 켭니다. 조직 계정은 관리자 허용이 필요할 수 있습니다.
3. 이름을 **한눈AI**, 서버 주소를 가이드에서 복사한 MCP 주소로 입력합니다.
4. 인증 방식은 **인증 없음**을 선택합니다.
5. 도구 검색·앱 추가와 필요한 연결 승인을 마칩니다.
6. 새 채팅에서 앱 메뉴 또는 **@한눈AI**로 선택하고 “다음 내용을 한눈AI로 정리해 줘”라고 요청합니다.

메뉴 제공 여부는 ChatGPT 계정·요금제·조직 정책에 따라 다릅니다. 메뉴가 없다면 한눈AI 웹 또는 Chrome 확장을 이용하세요. 앱에 따라 이미지 표시 방식도 달라질 수 있습니다.

[공식 OpenAI 연결 안내](https://developers.openai.com/plugins/deploy/connect-chatgpt)

### Codex CLI

아래 주소를 실제 서비스 주소로 바꾸세요. 웹 가이드에는 현재 주소가 반영된 명령이 표시됩니다.

```text
codex mcp add hannoon --url https://YOUR-SERVICE.example/mcp
```

`codex mcp list`로 확인한 뒤 채팅에서 한눈AI 도구를 사용해 달라고 요청하세요.

[공식 Codex MCP 안내](https://learn.chatgpt.com/docs/extend/mcp?surface=cli)

### Claude Code

```text
claude mcp add --transport http hannoon https://YOUR-SERVICE.example/mcp
```

실제 주소로 바꾸어 실행하고 Claude Code 채팅에서 `/mcp`를 입력해 연결 상태를 확인합니다. 필요한 실행 승인은 사용자가 진행합니다.

[공식 Claude Code MCP 안내](https://code.claude.com/docs/en/mcp)

새 PC와 다른 AI 채팅 환경에서는 연결을 다시 추가하세요. 해제는 해당 서비스의 앱·MCP 설정에서 합니다. 작업의 임시 접근 정보나 결과를 다른 사람에게 공유하면 해당 자료에 접근할 수 있으므로 공유 범위를 확인하세요.

## 문제가 생겼을 때

| 상황 | 해결 방법 |
|---|---|
| 파일을 읽지 못함 | 형식·10MB 이하·텍스트형 PDF인지 확인하고 필요한 본문을 복사해 입력합니다. |
| 앞부분만 읽었다는 안내 | 글자 수나 PDF 페이지 한도를 넘었습니다. 필요한 구간만 입력하거나 파일을 나눕니다. |
| URL 본문 가져오기 실패 | Chrome 현재 페이지 정리 또는 텍스트 입력을 사용합니다. |
| 현재 페이지 접근 불가 | 일반 웹페이지를 열거나 본문을 직접 입력합니다. |
| 이미지 복사 실패 | PNG 다운로드로 저장합니다. |
| 이용 한도 도달 | 진행 중 작업 완료 후 또는 다음 날 다시 이용합니다. |
| 예전 결과를 못 찾음 | 보관 기한 또는 브라우저 접근 정보가 만료됐을 수 있습니다. 다시 생성하고 이미지를 저장합니다. |

웹의 **개인정보 안내**에서 자료 처리와 보관 방식을 확인하세요.
