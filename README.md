# 한눈AI

복잡한 내용을 **60자 이내 한 문장**과 **내용에 맞는 다이어그램 이미지**로 정리합니다. 원문의 근거·조건·관계를 대조하고, 발견한 문제는 정해진 처리 한도 안에서 수정합니다.

## 바로 사용하기

[한눈AI 바로 사용하기](https://hannoon-ai-diagram.jgbaek100.chatgpt.site)

웹에서 텍스트·URL을 붙여넣거나 파일을 선택한 뒤 **다이어그램 만들기**를 누르세요. **회원가입·로그인·AI API 키 입력·프로그램 설치가 필요 없습니다.** 결과는 **이미지 복사** 또는 **PNG 다운로드**로 저장합니다.

웹 상단 **사용가이드**에서 파일 준비 방법과 Chrome 확장·MCP 연결 절차를 확인할 수 있습니다. 문서로 읽으려면 [사용가이드](docs/USER_GUIDE.md)를 여세요.

- **Chrome 확장:** 사용가이드에서 내려받아 설치하면 현재 열린 페이지를 정리할 수 있습니다. 개발자 모드·폴더 선택·권한 승인은 사용자가 직접 진행합니다.
- **MCP:** 서비스 주소 뒤의 `/mcp`를 ChatGPT·Codex·Claude Code에 추가합니다. **공개 chatgpt.site 서비스는 플랫폼 OAuth 인증**을 사용하므로 기존 플랫폼 계정으로 연결을 승인합니다. 별도의 한눈AI 회원가입이나 AI API 키 입력은 없습니다. 직접 운영하는 Workers 배포의 기본 MCP 인증은 **인증 없음**입니다. 해당 AI 서비스의 계정·요금제와 연결 승인은 별도입니다.

공개 저장소는 소스 배포 위치입니다. 코드를 내려받는 것과 운영 중인 서비스에 접속하는 것은 다릅니다. 일반 사용자는 서비스 주소만 열면 됩니다.

## 입력과 결과

| 항목 | 지원 범위 |
|---|---|
| 텍스트 | 최대 12,000자 |
| URL | 공개 웹페이지의 본문 |
| 파일 | 10MB 이하의 txt, docx, html, hwpx, 텍스트형 pdf |
| 다이어그램 | 흐름·의사결정·계층·개념 지도·타임라인·순환·비교·시스템 구성 |
| 결과 | 60자 이내 한 문장 요약과 다이어그램 이미지 |

파일 본문은 브라우저에서 읽고, **만들기**를 눌렀을 때 추출한 텍스트를 분석 서버로 보냅니다. 원본 파일 전체를 서버에 업로드하지 않습니다. PNG 변환도 브라우저에서 처리합니다.

이미지형 PDF의 OCR은 지원하지 않습니다. PDF는 최대 80페이지를 확인하며, 분량을 넘기거나 일부 내용만 읽은 경우 안내를 표시합니다. 로그인 페이지는 Chrome 확장의 현재 페이지 기능이나 텍스트 입력을 이용하세요. 자동 검증은 정확성 보장이 아니므로 중요한 수치·조건·관계는 원문과 함께 확인하세요.

## 직접 운영하기

구성은 **Cloudflare Workers + D1 + 정적 웹 자산**입니다. Gemini·OpenAI·Anthropic API를 지원하며, 제공업체 키는 서버의 **Secret**에만 저장합니다. 브라우저·확장 프로그램·공개 GitHub 저장소에는 키를 배포하지 않습니다.

Node.js와 Cloudflare 계정을 준비하고 저장소에서 다음을 진행합니다.

```text
npm ci
npx wrangler login
npx wrangler d1 create hannoon-ai
```

발급된 데이터베이스 ID를 `wrangler.jsonc`의 `d1_databases`에 넣고 바인딩 이름 `DB`를 유지합니다. 다음으로 스키마와 비밀값을 설정합니다. 비밀값은 명령이 표시하는 입력 창에 입력하며 명령 인수에 넣지 않습니다.

```text
npx wrangler d1 migrations apply DB --remote
npx wrangler secret put LLM_API_KEY
npx wrangler secret put SERVICE_SECRET
```

`SERVICE_SECRET`에는 32자 이상의 충분히 긴 무작위 값을 사용하세요. 빌드 환경의 `SITE_ORIGIN`을 실제 HTTPS 서비스 주소로 설정한 후 빌드·배포합니다. 처음 주소가 확정되면 해당 주소로 다시 빌드하여 확장 다운로드에도 반영합니다.

```text
npm run build
npm run deploy
```

환경변수·사용량 제한·키 교체·Chrome 배포·MCP와 자료 보관에 대한 자세한 설명은 [운영가이드](docs/OPERATOR_GUIDE.md)에 있습니다. 다른 사람이 독립 서비스를 운영할 때는 자신의 호스팅과 AI API 키를 설정해야 합니다.

**Cloudflare 무료 범위와 AI API 비용은 별개입니다.** 무료 호스팅에는 요청·CPU·저장·쿼리 한도가 있고, AI 호출에는 제공업체의 할당량이나 요금이 적용됩니다. 무제한 무료 생성이나 무제한 동시 접속을 보장하지 않습니다. 서비스는 익명 세션·IP·전체 생성량과 AI 호출 수에 제한을 둡니다.

## 소스 구조

| 경로 | 역할 |
|---|---|
| `server/agent.mjs` | 원문 근거 단위 생성, AI 구조화, 구조 검사, 의미 대조와 제한된 수정 |
| `server/layout.mjs` | 입력 문자를 이스케이프하는 8종 SVG 다이어그램 렌더러 |
| `server/store.mjs` | D1 작업 상태, 호출 예산 예약·정산, 중복 요청과 작업 진행 제어 |
| `server/security.mjs` | 익명 세션 서명, CSRF, 접근 정보와 임시 상태 암호화 |
| `server/urls.mjs` | 공개 URL의 범위·크기를 제한한 본문 가져오기 |
| `server/app.mjs` | 웹 API·MCP·결과 조회·정적 자산 라우팅 |
| `web/` | 한국어 웹 UI, 브라우저 문서 추출과 PNG 변환 |
| `chrome-extension/` | Chrome 현재 페이지·텍스트·파일 입력과 결과 활용 |
| `drizzle/`, `db/` | D1 마이그레이션과 스키마 |
| `scripts/` | 문서 파서·웹·확장 배포 자산 빌드 |

컴파일러는 JavaScript로 구현한 단계형 상태 머신입니다. **구조화 → 형식·관계 검사 → 원문 의미 대조 → 필요한 수정 → SVG 렌더링** 순서로 처리하며, 작업당 최대 6회 AI 호출과 최대 2회 수정을 허용합니다. 각 단계는 요청에 따라 진행되고 임시 상태는 D1에 암호화하여 보관합니다. AI가 생성한 코드나 SVG를 실행하는 방식은 사용하지 않습니다.

## 개발과 공개

```text
npm ci
npm test
npm run build
```

로컬 실행은 `.dev.vars.example`을 `.dev.vars`로 복사해 비밀값을 설정하고, `npx wrangler d1 migrations apply DB --local` 이후 `npm run dev`로 시작합니다. `.dev.vars`는 커밋하지 않습니다.

작업 중 원문은 임시로 암호화해 저장하고 완료·실패 시 삭제합니다. 결과와 중단된 작업은 기본 24시간 만료 정책을 적용합니다. 익명 세션이나 작업 접근 정보를 공유하면 다른 사람이 결과에 접근할 수 있으므로 보호하세요. 자세한 내용은 [보안 안내](SECURITY.md)와 웹의 **개인정보 안내**를 확인하세요.
