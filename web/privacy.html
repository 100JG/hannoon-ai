계정을 만들지 않고 사용하는 한눈AI의 기본 데이터 처리 방식을 안내합니다.

자료 입력과 AI 분석

만들기 버튼을 누르면 입력 텍스트, URL에서 가져온 본문 또는 파일에서 읽은 본문을 서버가 분석합니다. 이 본문은 운영자가 설정한 AI 제공업체로 전송됩니다. AI 제공업체의 데이터 처리·보관은 해당 업체와 운영자가 사용하는 API 계약 및 설정의 적용을 받습니다.

파일은 브라우저 안에서 텍스트를 추출하며 파일 원본 전체를 서버로 업로드하지 않습니다. 추출한 본문은 만들기 버튼을 눌렀을 때 전송합니다. 공개 URL을 입력한 경우 서버가 해당 웹페이지를 요청하므로 연결 대상 사이트가 그 접속을 기록할 수 있습니다.

저장하는 정보와 보관 기간

정보처리 방식
분석할 본문작업 진행을 위해 서버 저장소에 암호화해 임시 저장합니다. 완료·실패 처리 시 본문을 지우며, 중단된 작업은 최대 24시간의 만료 기준에 따라 정리합니다.
요약·결과 이미지·작업 상태기본 24시간 동안 보관하고 만료 후 삭제합니다. 필요한 결과는 바로 다운로드하세요.
임시 접근 정보브라우저 쿠키 또는 확장의 세션 저장소를 이용해 본인의 작업 결과에 접근합니다. 이름·이메일·비밀번호를 요구하는 한눈AI 계정은 만들지 않습니다.
이용량 제한 정보익명 세션과 IP 주소의 단방향 식별값, 서비스 전체 호출 수로 과도한 이용을 제한합니다. 호스팅·프록시의 접속 기록은 운영 환경의 정책에 따릅니다.

만료된 자료는 요청 또는 주기적 정리 시 삭제하며, 이미 만료된 결과의 접근은 차단합니다. 내려받았거나 다른 AI 채팅으로 전달된 자료는 해당 저장 위치에서 직접 삭제해야 합니다. 호스팅 백업의 보관·삭제는 운영자의 백업 정책에 따릅니다.

Chrome 확장 프로그램 권한

  • 현재 페이지 정리 버튼을 눌렀을 때 현재 탭의 보이는 본문을 읽습니다.
  • 방문 기록과 다른 탭을 계속 읽거나 쿠키·비밀번호를 수집하는 기능을 두지 않습니다.
  • 페이지의 본문에 개인정보가 있으면 해당 내용도 포함될 수 있으므로 보내려는 자료를 확인하세요.
  • 서비스 연결을 위한 임시 접근 정보와 최근 작업의 본문·식별자를 Chrome 세션 저장소에 보관합니다. 브라우저를 완전히 종료하면 최근 결과를 다시 열지 못할 수 있습니다.
  • 지우기 버튼으로 최근 입력·결과 표시를 비울 수 있고, Chrome 확장 관리 화면에서 프로그램을 제거할 수 있습니다.

MCP로 연결한 AI 채팅

ChatGPT·Codex·Claude Code 등에서 한눈AI 도구 사용을 요청하면 해당 채팅 서비스가 선택한 원문을 한눈AI에 보냅니다. 처리 후 요약과 결과 이미지를 반환합니다. 이용 중인 AI 채팅 서비스에도 내용이 전달되므로 그 서비스의 정책도 적용됩니다.

한눈AI 계정 로그인과 API 키 입력 없이 연결합니다. 작업 결과 접근을 위한 임시 정보는 도구가 자동으로 관리합니다. 이 정보나 결과를 다른 사람에게 공유하면 해당 자료에 접근할 수 있으므로 공유 범위를 확인하세요. AI 제공업체 API 키는 웹·확장·MCP 클라이언트로 전달하지 않습니다.

자료를 다룰 때

개인정보·비밀번호·API 키는 입력 자료에 포함하지 마세요. 결과에 개인정보가 포함되면 이미지나 채팅을 공유하기 전에 확인하세요. 공용 PC에서는 필요한 이미지를 보관한 뒤 입력을 지우고 브라우저 사이트 데이터를 정리하세요.

서비스의 데이터 처리나 보관에 관한 문의는 서비스 주소를 안내한 운영자에게 전달하세요. 운영자는 실제 호스팅·AI 제공업체·연락 경로와 백업 정책에 맞는 공개 운영 안내를 제공해야 합니다.
