01 · START

웹에서 바로 정리하기

한눈AI는 회원가입·로그인·AI API 키 입력 없이 사용할 수 있습니다. 일반 사용자는 프로그램을 설치할 필요도 없습니다.

  1. 한눈AI 서비스 주소를 여세요.

    PC나 휴대전화의 브라우저에서 접속하세요.

  2. 정리할 자료를 넣으세요.

    텍스트나 URL을 붙여넣거나 파일을 선택하세요. 파일을 선택하면 이름과 용량이 표시됩니다.

  3. 다이어그램 만들기를 누르세요.

    내용에 맞는 다이어그램을 선택하고 원문과 확인한 뒤, 60자 이내 한 문장과 이미지로 보여줍니다.

공개 웹페이지 주소를 넣으세요. 로그인이 필요한 페이지나 가져오기가 차단된 사이트는 Chrome 확장 또는 텍스트 입력을 이용하세요.

＋

파일

최대 10MB. txt, docx, html, hwpx, pdf(텍스트로 인식되지 않는 이미지형 PDF 파일은 제외)

PDF를 먼저 확인해 주세요.

문장을 마우스로 선택해 복사할 수 있어야 합니다. 스캔한 종이처럼 글자가 이미지인 PDF는 지원하지 않습니다. PDF는 최대 80페이지까지 확인하며, 분량을 넘으면 파일을 나누어 주세요.

파일의 본문은 브라우저 안에서 읽습니다. 선택한 파일 원본 전체를 서버에 업로드하지 않습니다. 만들기 버튼을 눌렀을 때 추출한 본문을 서버로 보내 분석합니다. 일부 페이지만 읽혔거나 글자 수를 넘었다는 안내가 나오면, 필요한 구간을 직접 선택하거나 문서를 나누어 주세요. 표·그림·수식의 배치 의미는 텍스트만으로 완전히 전달되지 않을 수 있습니다.

03 · RESULT

결과를 활용하세요

  • 한 문장 요약60자 이내로 핵심을 빠르게 확인합니다.
  • 다이어그램순서, 비교, 관계, 시간 흐름 등 내용에 맞춰 정리합니다.
  • 이미지 복사메신저나 문서에 바로 붙여넣습니다. 복사가 안 되면 다운로드를 이용하세요.
  • PNG 다운로드이미지를 PC나 휴대전화에 저장합니다.
  • 다시 생성하기같은 원문으로 결과를 새로 만듭니다. 새 생성도 이용 한도에 포함됩니다.
  • 지우기입력 화면을 비우고 새 자료를 준비합니다.

AI가 정리한 결과에는 누락이나 해석 차이가 있을 수 있습니다. 하단에 확인 안내가 보이면 원문의 조건·숫자·관계를 함께 살펴보세요. 중요한 판단에 쓰기 전에는 원문을 확인하세요.

결과의 기본 보관 기간은 24시간입니다. 브라우저를 종료하거나 사이트 데이터를 지우면 최근 결과를 다시 열기 어려울 수 있으므로 필요한 이미지는 바로 저장하세요. 서비스와 접속 환경을 기준으로 이용량을 제한하며, 전체 사용량과 대기 상황에 따라 일시적으로 이용이 제한될 수 있습니다.

04 · CHROME EXTENSION

지금 보는 페이지를 바로 정리하세요

Chrome 확장을 설치하면 웹페이지를 복사하지 않고도 본문을 정리할 수 있습니다. 웹만 이용한다면 설치는 선택 사항입니다.

이 단계는 사용자가 직접 진행해야 합니다.

Chrome의 확장 프로그램 설치와 권한은 사용자가 승인해야 합니다. 아래 순서대로 한 번만 설치하세요.

  1. 확장 프로그램을 다운로드하세요.

    아래 버튼을 눌러 ZIP을 저장하세요. 이 서비스 주소가 이미 설정되어 있습니다.

    Chrome 확장 프로그램 다운로드 ↓
  2. ZIP의 압축을 푸세요.

    Windows: ZIP을 마우스 오른쪽 버튼으로 누르고 ‘압축 풀기’를 선택하세요. Mac: ZIP을 두 번 클릭하세요. 압축을 푼 폴더는 삭제하거나 옮기지 마세요.

  3. Chrome의 확장 프로그램 화면을 여세요.

    주소창에 chrome://extensions를 입력하고 Enter를 누르세요. 우측 상단 ‘개발자 모드’를 켜세요.

  4. 압축을 푼 폴더를 선택하세요.

    ‘압축해제된 확장 프로그램을 로드합니다’를 누르세요. ZIP 자체가 아니라 manifest.json 파일이 들어 있는 폴더를 선택하세요. 한눈AI 카드가 나타나면 설치 완료입니다.

  5. 아이콘을 고정하고 페이지를 여세요.

    Chrome 우측 상단 퍼즐 모양 아이콘 → 한눈AI 옆 핀을 누르세요. 정리할 웹페이지를 연 뒤 한눈AI 아이콘을 누르세요.

  6. 현재 페이지 정리하기를 누르세요.

    처음에 서비스 연결 권한을 요청하면 한눈AI 서비스 주소인지 확인하고 허용하세요. API 키 입력이나 로그인은 필요 없습니다. ‘크게 보기’는 한눈AI 웹페이지를 엽니다.

권한은 어디에 쓰나요?

현재 탭 권한은 사용자가 정리 버튼을 눌렀을 때 그 페이지의 보이는 본문을 읽는 데 사용합니다. 방문 기록을 수집하거나 다른 탭을 계속 읽지 않습니다. 서비스 연결 권한은 분석 요청과 결과 조회에 필요합니다.

Chrome 설정 화면, 웹 스토어, 일부 PDF 뷰어, 영상 중심 페이지는 본문을 읽을 수 없습니다. 이때는 텍스트·파일 입력을 이용하세요. 팝업을 닫았다가 다시 열면 최근 작업을 불러옵니다. 브라우저를 완전히 종료하면 최근 작업에 다시 접근하지 못할 수 있으므로 결과를 저장하세요.

업데이트하거나 제거하려면

새 ZIP을 받아 압축을 푼 뒤 확장 프로그램 화면에서 기존 한눈AI를 제거하고 새 폴더를 로드하세요. 더 이상 쓰지 않으면 한눈AI 카드의 ‘삭제’를 누르세요. Chrome 웹 스토어 링크가 별도로 제공된 경우에는 해당 링크의 설치 버튼과 권한 승인으로 설치할 수 있습니다.

05 · MCP CONNECTION

AI 채팅에서도 한눈AI를 사용하세요

MCP는 AI 채팅에 한눈AI 도구를 연결하는 기능입니다. 한눈AI 계정이나 AI API 키는 필요 없습니다. 이용 중인 AI 채팅 서비스의 계정·권한은 별도이며 연결 추가와 도구 실행 승인은 사용자가 진행합니다.

한눈AI MCP 주소이 서비스 주소 뒤에 /mcp를 붙이세요.

ChatGPT 웹에서 연결

  1. ChatGPT 앱 설정을 여세요.

    설정 → 앱에서 ‘만들기’ 또는 사용자 지정 앱 추가 항목을 찾으세요. 계정에서 요구하면 고급 설정의 개발자 모드를 켜세요. 조직 계정은 관리자의 허용이 필요할 수 있습니다.

  2. 이름과 서버 주소를 입력하세요.

    이름은 ‘한눈AI’, 서버 주소는 위에서 복사한 MCP 주소를 넣으세요. 인증 방식은 ‘인증 없음’을 선택하세요. 별도의 한눈AI 로그인은 없습니다.

  3. 연결을 승인하고 채팅에서 선택하세요.

    도구 검색과 앱 추가를 마친 뒤 새 채팅의 앱 메뉴 또는 @한눈AI로 선택하세요. 화면에 도구 실행 승인이 나타나면 내용을 확인하고 승인하세요.

  4. 자료를 넣고 정리해 달라고 요청하세요.

    “다음 내용을 한눈AI로 정리해 줘”라고 요청하고 원문을 붙여넣으세요. 채팅 앱이 작업을 생성하고 완료된 결과를 가져옵니다. 앱에 따라 이미지 표시 방식은 다를 수 있습니다.

앱 추가 메뉴와 개발자 모드 제공 여부는 ChatGPT 요금제·조직 정책에 따라 달라집니다. 메뉴가 없다면 한눈AI 웹이나 Chrome 확장을 이용하세요. 공식 OpenAI 연결 안내

Codex CLI에서 연결하기

Codex CLI가 설치되어 있다면 터미널에서 아래 명령을 실행하세요.

codex mcp add hannoon --url https://YOUR-SERVICE.example/mcp

codex mcp list로 연결을 확인한 뒤 채팅에서 한눈AI 도구를 사용해 달라고 요청하세요. 공식 Codex MCP 안내

Claude Code에서 연결하기

Claude Code가 설치되어 있다면 아래 명령을 실행하세요. 채팅에서 /mcp를 입력해 한눈AI 연결 상태를 확인하고 필요한 승인을 완료하세요.

claude mcp add --transport http hannoon https://YOUR-SERVICE.example/mcp

공식 Claude Code MCP 안내

새 PC와 다른 AI 채팅 환경에서는 연결 추가를 다시 진행하세요. 연결 해제는 해당 서비스의 앱·MCP 설정에서 할 수 있습니다. 채팅에 반환된 작업의 임시 접근 정보는 다른 사람에게 공유하지 마세요.

06 · HELP

사용 중 궁금할 때

파일에서 텍스트를 읽지 못해요.

지원 형식과 10MB 이하인지 확인하세요. 이미지형 PDF, 암호가 걸린 파일, 손상된 파일은 읽지 못할 수 있습니다. 텍스트를 선택할 수 있는 파일을 사용하거나 본문을 복사해 입력하세요.

자료 앞부분만 읽혔다고 나와요.

입력 글자 수나 PDF 페이지 수를 넘은 상태입니다. 필요한 구간만 텍스트로 붙여넣거나 문서를 나누세요. 전체를 읽은 것처럼 자동 분석하지 않도록 안내합니다.

현재 페이지를 읽지 못해요.

일반 웹페이지를 먼저 열어 주세요. Chrome 내부 화면과 일부 PDF 뷰어는 확장이 읽을 수 없습니다. 필요한 부분을 텍스트로 입력하거나 파일을 선택하세요.

이용 한도에 도달했어요.

서비스 전체 또는 접속 환경의 일일 한도·동시 처리 한도에 도달한 상태입니다. 진행 중인 작업이 있으면 완료 후, 일일 한도라면 다음 날 다시 이용해 주세요.

이미지 복사가 안 돼요.

브라우저 클립보드 권한을 허용해야 할 수 있습니다. 계속 안 된다면 PNG 다운로드로 저장한 뒤 파일을 이용하세요.

이전에 만든 결과가 없어졌어요.

결과 보관 기간이 지났거나 브라우저의 임시 접근 정보가 지워졌을 수 있습니다. 원문으로 다시 생성하고 필요한 결과는 다운로드해 보관하세요.
